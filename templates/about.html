Project Overview

This platform demonstrates:

  • eCommerce catalog and subscriptions for micro-desalination units.
  • Role-based authentication and secure session management.
  • Environmental metrics dashboard via JWT-authenticated API.
  • Production-ready security settings (HTTPS, HSTS, CSRF, XSS protections).

Technologies Used

  • Django 4.2+ with Django REST Framework for backend and API.
  • Bootstrap 5.3 for responsive frontend design.
  • MySQL for relational database management.
  • GitHub Actions for CI/CD pipelines.
  • Third-party APIs for telemetry data integration.
