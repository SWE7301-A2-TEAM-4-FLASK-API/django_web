## Development Methodology

### Agile & Collaborative Approach

Our team follows an **Agile development methodology** to ensure rapid, iterative progress and continuous improvement. The process is structured around short sprints, regular stand-ups, and collaborative planning sessions. Each team member is assigned clear responsibilities, and we use version control (Git) for code management and peer reviews.

### Key Practices

- **Feature Branch Workflow:**  
  Each new feature or bug fix is developed in its own branch, ensuring isolation and easy integration.

- **Code Reviews:**  
  All code changes are reviewed by at least one other team member before merging to the main branch, ensuring code quality and shared understanding.

- **Continuous Integration:**  
  Automated tests are run on every push to catch issues early and maintain stability.

- **Documentation:**  
  All major features and architectural decisions are documented in the README and relevant code files.

- **Environment Separation:**  
  We use SQLite3 for development to enable rapid setup and testing, while MySQL is reserved for production deployments. This is documented and enforced in `settings.py` and `.env`.

### Workflow Steps

1. **Planning:**  
   Requirements are discussed and broken down into user stories and tasks. Each story includes a clear Definition of Done.

2. **Development:**  
   Developers work on assigned tasks, following the feature branch workflow. Code is committed frequently with descriptive messages.

3. **Testing:**  
   Unit and integration tests are written for new features. The test suite is run before every merge.

4. **Review:**  
   Code is reviewed and discussed. Suggestions are incorporated before merging.

5. **Deployment:**  
   Once features are complete and tested, they are deployed to the staging or production environment.

6. **Retrospective:**  
   After each sprint, the team reviews what went well and what can be improved.

### Tools Used

- **Git & GitHub:** Version control and collaboration
- **Django:** Main web framework
- **Flask:** API services
- **SQLite3:** Development database
- **MySQL:** Production database
- **VS Code:** Preferred IDE
- **Python-dotenv:** Environment variable management

### Team Collaboration

Each member contributed to different modules (accounts, products, subscriptions, metrics) and documentation. Regular communication and updates ensured alignment and quick resolution of blockers.
